# Тех. карты Mezzome

Сайт для кухни: 356 тех. карт (после сверки с Word-ТТК и приведения нетто к выходу порции) и калькулятор закладки.
Повара входят по логину и паролю, правят нормы и сохраняют — изменения сразу видят все. Каждая правка подписана именем и попадает в историю карты.

**Вход:** логин `0000`, пароль `0000` (меняется в настройках Render: `APP_LOGIN`, `APP_PASSWORD`).

## Что умеет
- Поиск блюд, фильтры «не сходятся / проверить / изменены», категории.
- Правка выхода, продуктов (поиск по названию или коду SAP), брутто, нетто, технологии; примечания «было → стало».
- Полоса «сумма нетто / выход порции» и кнопка «Подогнать нетто под выход» (все продукты одинаково).
- Калькулятор: N мармиток × порций в одной + сколько всего продуктов ушло → нормы на 1 порцию; в обратную сторону — закладка на N порций по карте; запись норм в карту.
- История правок, защита от одновременного сохранения, черновики на устройстве, печать карты, выгрузка всех карт в CSV для Excel.

## Запуск на компьютере
```
node server.js        # Node 18+, зависимости не нужны
```
Откройте http://localhost:3000. Правки сохраняются в папку `storage/`.

## Выложить на GitHub
1. github.com → **New repository** → имя, например `mezzome-techcards` → **Private** → Create.
2. **Add file → Upload files** → перетащите все файлы и папки из архива (server.js, package.json, render.yaml, README.md, папки `public` и `data`) → **Commit changes**.

## Запуск на Render (с диском, рекомендуется)
1. render.com → войдите через GitHub → **New → Blueprint** → выберите репозиторий → **Apply**.
2. Render создаст сервис по `render.yaml`: тариф Starter и диск 1 ГБ для правок.
3. Через 2–3 минуты откройте адрес вида `https://mezzome-techcards.onrender.com` и отправьте его поварам.

## Бесплатно (без диска)
На бесплатном тарифе Render диск не подключается, а файлы стираются при каждом перезапуске — правки поваров пропадут.
Чтобы этого не было, подключите бесплатную базу PostgreSQL (например, neon.tech или supabase.com):
1. Создайте базу и скопируйте строку подключения (`postgres://…`).
2. На Render: **New → Web Service** → репозиторий → Runtime **Node**, Build `npm install`, Start `node server.js`, Instance **Free**.
3. В **Environment** добавьте: `DATABASE_URL` = строка подключения, `APP_LOGIN` = `0000`, `APP_PASSWORD` = `0000`, `SESSION_SECRET` = любая длинная строка.
Таблица создаётся сама. Бесплатный сервис Render «засыпает» без посещений: первое открытие занимает до минуты.

## Безопасность
Пароль `0000` угадать легко. Если по ссылке будут заходить посторонние, поменяйте `APP_PASSWORD` на более сложный.

## Обновить карты
Исходные карты лежат в `data/base.json`. Правки поваров хранятся отдельно и поверх исходных; выгрузка всех карт с правками — меню с именем → «Скачать все карты для Excel».
